# FreelaBoard v0.2.0 Release Notes

FreelaBoard v0.2.0 is a local-first Windows desktop app for freelance project operations.

## Included

- Project registration, editing, and deletion
- Status management
- Deadline tracking with overdue and upcoming highlights
- Invoice status and payment status tracking
- CSV export
- Local SQLite persistence
- Windows notification-area deadline alerts
- Optional resident mode when the window is closed
- Tray icon right-click menu for opening the panel or exiting
- Single-file EXE build

## Recommended Release Asset

Attach:

```text
dist\FreelaBoard.exe
```

Do not commit `dist/` directly to the repository.
