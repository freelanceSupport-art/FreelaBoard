# FreelaBoard Landing Copy

## Headline

FreelaBoard

## Short Value Proposition

A local Windows cockpit for freelance projects, deadlines, invoices, and payment status.

## Product Summary

FreelaBoard is built for freelancers who want to manage day-to-day project operations without moving client work into a cloud dashboard. Register projects, track deadlines, mark invoice and payment states, export CSV reports, and receive deadline alerts from the Windows notification area.

## Key Benefits

- Local-first: project data is saved to SQLite on your machine.
- Deadline-aware: overdue and upcoming projects stand out immediately.
- Billing-aware: invoice and payment status stay visible beside each project.
- Portable: the app is distributed as a single Windows EXE.
- Practical: CSV export makes handoff and reporting simple.

## Suggested CTA

Download FreelaBoard for Windows

## Audience

- Freelancers managing several small-to-mid-sized projects
- Solo operators who need deadline and invoice visibility
- Creators who prefer a desktop tool over a cloud subscription
